## 📖 About This Project

This repository contains the complete source code of my personal portfolio website — a **fully responsive, animated, and data-driven** web application designed to showcase my skills, projects, certificates, and professional journey.

Built with a modern tech stack and a strong focus on user experience, the portfolio features a **cinematic dark theme** with neon indigo accents, smooth scroll-triggered animations, and a unique interactive **3D notebook animation** in the "About Me" section.

The project reflects my passion for clean code, thoughtful design, and building things from scratch — values I carry into every line of code I write.

---

## ✨ Highlights

- 🎨 **Cinematic UI** — Dark theme with neon indigo gradients, glassmorphism, and smooth scroll-triggered animations powered by **Motion (Framer Motion)**.
- 📖 **Interactive 3D Notebook** — A unique scroll-based notebook animation in the About section (desktop) and a tap-to-open experience (mobile).
- 📡 **Dynamic Data Fetching** — Projects, skills, timeline, certificates, and testimonials are fetched from a custom Node.js/Express backend API, with local fallback data for resilience.
- 📱 **Fully Responsive** — Optimized for every device, from mobile phones to large desktop screens.
- 🗂️ **Project Detail Pages** — Dedicated routes for each project featuring key features, tech stack, screenshots, and personal insights.
- 📄 **Smart Pagination** — Smooth pagination for the projects gallery.
- 📬 **Contact Integration** — Direct email integration and a contact modal.
- 🔍 **SEO Optimized** — Includes Open Graph meta tags for social sharing.

## 📂 Project Sections

The portfolio is organized into the following sections:

- **Hero** — A cinematic landing with animated gradient orbs and CTA.
- **Stats** — Key numbers (months of work, skills, certificates).
- **About** — The interactive 3D notebook experience.
- **Resume** — An animated timeline of my education and journey.
- **Skills** — Technical skills (with animated bars), tools, and soft skills.
- **Projects** — A paginated gallery with detailed project pages.
- **Certificates** — Awards and courses earned.
- **Testimonials** — Quotes from professors and colleagues.
- **Contact** — Email, phone, location, and a contact form.
